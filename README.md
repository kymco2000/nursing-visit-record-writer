# 🩺 居家護理與安寧訪視紀錄自動化撰寫與知識庫提煉技能 (Nursing Visit Record Writer)

> 專為居家護理師、安寧個管師、長照訪查員與社工設計的 AI 智能寫作工具、標準化格式引擎與臨床知識庫提煉系統。  
> 只要輸入現場隨手記下的**零散關鍵字**或**訪視錄音檔**，AI 不僅能產出 800 字以內的標準訪視紀錄，還能自動將臨床處置手法與藥物指引**提煉為知識卡片**存入 Obsidian 知識庫！

---

## 🌟 核心特色

1. **零散關鍵字秒轉正式報告**：在案家現場時間緊迫，只需隨手記錄簡短重點或語音輸入，AI 自動辨識並映射至各臨床維度。
2. **內建音訊轉譯腳本 (Faster-Whisper)**：支援直接讀取 `.wav` / `.mp3` / `.m4a` 訪視錄音檔，快速產出繁中逐字稿與時間碼字幕。
3. **符合臨床評鑑之黃金三段式結構**：
   - `#醫療症狀處理:`（症狀評估、跨專業醫師溝通、階梯藥物調整、藥盒管理）
   - `#舒適照護：`（生命徵象量化、傷口分期測量、專科減症處置、前後成效量化驗證）
   - `心理社會靈性照護輔導紀錄` $\rightarrow$ `#標題:`（照顧者負荷、家庭歷史原話引錄、族語溝通、靈性禱告/四道人生）
4. **🧠 知識庫自動提煉與歸檔 (Second Brain Integration)**：
   - 自動連上 Obsidian / 第二大腦，將訪視中涉及的專科護理（如低血鉀 K-Glu 補鉀指引、灰指甲清創防蜂窩性組織炎SOP、美康+施美調配手法、四道人生靈性引導）提煉為獨立的「概念卡片」存入 `03_知識庫/01_概念卡片/`，讓實戰經驗化為個人與團隊的長青知識庫！
5. **嚴格字數約束**：訪視紀錄字數自動控制在 **800 字以內**，簡明扼要、直擊重點。
6. **標準化檔案命名規範**：自動採用 `YYYYMMDD個案名護理訪視紀錄.md` 命名，便於歸檔與檢索。

## 🚀 快速上手教學

### 方式一：訪視紀錄自動生成

直接在對話中貼上現場記錄的零碎關鍵字：

> **輸入範例**：  
> 「2026/07/02 吳興富阿公，居服員洗完澡，血壓偏低心跳103，抽血血鉀3.1偏低開K-Glu喝一瓶，換新藥盒分藥拍照給阿欣，十指灰指甲很長剪指甲洗手衛教，擦美康施美藥膏，光復受災戶獨居兒子少來，用族語跟他講話很開心，教他胸悶禱告，約下週複查。」

> **AI 產出**：自動輸出符合三段式標題、數據量化、包含原話引錄且在 800 字以內的標準護理紀錄！

---

### 方式二：自動提煉知識點卡片到 Obsidian

完成訪視紀錄後，只要對 AI 說「**將本次訪視中的低血鉀與灰指甲照護提煉成知識卡片**」，AI 就會自動產出結構化概念卡片，並存入你的 Obsidian `03_知識庫/01_概念卡片/` 中！

---

### 方式三：訪視錄音檔自動轉譯

```bash
python scripts/transcribe_audio.py --audio "路徑/你的錄音檔.wav" --output "輸出目錄"
```
