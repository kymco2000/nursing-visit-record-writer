# 🩺 居家護理與安寧訪視紀錄自動化撰寫技能 (Nursing Visit Record Writer)

> 專為居家護理師、安寧個管師、長照訪查員與社工設計的 AI 智能寫作工具與標準化格式引擎。  
> 只要輸入現場隨手記下的**零散關鍵字**或**訪視錄音檔**，AI 即可在數秒內自動擴寫為臨床專業、客觀量化、具備靈性溫度且**字數嚴格控制在 800 字以內**的標準護理訪視紀錄！

---

## 🌟 核心特色

1. **零散關鍵字秒轉正式報告**：在案家現場時間緊迫，只需隨手記錄簡短重點或語音輸入，AI 自動辨識並映射至各臨床維度。
2. **內建音訊轉譯腳本 (Faster-Whisper)**：支援直接讀取 `.wav` / `.mp3` / `.m4a` 訪視錄音檔，快速產出繁中逐字稿與時間碼字幕。
3. **符合臨床評鑑之黃金三段式結構**：
   - `#醫療症狀處理:`（症狀評估、跨專業醫師溝通、階梯藥物調整、藥盒管理）
   - `#舒適照護：`（生命徵象量化、傷口分期測量、專科減症處置、前後成效量化驗證）
   - `心理社會靈性照護輔導紀錄` $\rightarrow$ `#標題:`（照顧者負荷、家庭歷史原話引錄、族語溝通、靈性禱告/四道人生）
4. **嚴格字數約束**：全篇字數自動控制在 **800 字以內**，簡明扼要、直擊重點。
5. **標準化檔案命名規範**：自動採用 `YYYYMMDD個案名護理訪視紀錄.md` 命名，便於歸檔與檢索。

## 🚀 快速上手教學

### 方式一：直接在 AI 助理中使用（自然語言）

直接在對話中貼上現場記錄的零碎關鍵字：

> **輸入範例**：  
> 「2026/07/02 吳興富阿公，居服員洗完澡，血壓偏低心跳103，抽血血鉀3.1偏低開K-Glu喝一瓶，換新藥盒分藥拍照給阿欣，十指灰指甲很長剪指甲洗手衛教，擦美康施美藥膏，光復受災戶獨居兒子少來，用族語跟他講話很開心，教他胸悶禱告，約下週複查。」

> **AI 產出**：自動輸出符合三段式標題、數據量化、包含原話引錄且在 800 字以內的標準護理紀錄！

---

### 方式二：訪視錄音檔自動轉譯與紀錄生成

若手邊有現場訪視錄音檔（例如手機錄音或錄音筆檔案）：

1. 安裝環境需求：
   ```bash
   pip install faster-whisper
   ```
2. 執行轉譯腳本：
   ```bash
   python scripts/transcribe_audio.py --audio "路徑/你的錄音檔.wav" --output "輸出目錄"
   ```
3. 腳本會自動生成 `.txt` 逐字稿與 `.srt` 字幕，並由 AI 自動提煉為正式訪視紀錄！

## 📋 臨床紀錄黃金寫作原則

| 原則 | 說明 | 正確範例 |
| :--- | :--- | :--- |
| **數據量化** | 拒絕模糊字眼，以客觀數值呈現 | `GCS: E3V3M4`、`BT: 37.2°C`、`血鉀 3.1 mEq/L`、`壓瘡3度 8*10cm` |
| **成對因果** | 處置前問題 $\rightarrow$ 介入 $\rightarrow$ 處置後改善 | 挪動髖骨呻吟 $\rightarrow$ 翻身擺位完畢 $\rightarrow$ **呻吟情形緩和** |
| **藥物與手法** | 明確標註學名、劑型與手法 | `口服 K-Glu 補鉀藥水`、`黃花油腸胃道按摩`、`Fentanyl 貼片` |
| **原話引錄** | 涉及家庭矛盾或心理創傷時引用原話 | 案媳述：「以前我是阿美族嫁到太魯閣族村莊，婆婆當時就不是很喜歡我...」 |
| **文化賦能** | 記錄母語互動與靈性安頓 | 切換族語對話長者放鬆配合，引導四道人生或禱告 |
